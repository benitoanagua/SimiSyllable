# Initial Component Matrix

| Component | Category | Primary semantic | Slots | Events |
|---|---|---|---|---|
| `hh-icon` | primitive | image/decorative icon | none | none |
| `hh-button` | action | button | start, default, end | `hhPress` |
| `hh-icon-button` | action | button | none | `hhPress` |
| `hh-input` | form | input | none | `hhInput` |
| `hh-textarea` | form | textarea | none | `hhInput` |
| `hh-checkbox` | form | checkbox | none | `hhChange` |
| `hh-radio` | form | radio | none | `hhChange` |
| `hh-switch` | form | switch | none | `hhChange` |
| `hh-select` | form | select | default | `hhChange` |
| `hh-card` | content | article | header, default, footer | none |
| `hh-badge` | feedback | status | default | none |

This matrix is a HANDHELD contract and is not derived from STRATA APIs.
