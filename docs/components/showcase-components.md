# Showcase components

These components are intentionally compositional. They demonstrate the strengths of HANDHELD without introducing application/domain logic.

- `hh-metric-card`: responsive data emphasis and component slots.
- `hh-status`: compact semantic state.
- `hh-alert`: feedback, tone and composition.
- `hh-empty-state`: empty content with icon/action slots.
- `hh-data-table`: native table semantics, numeric alignment and responsive overflow.
- `hh-toolbar`: responsive composition using named slots.

They are suitable for product surfaces and documentation examples, but remain domain-agnostic.
