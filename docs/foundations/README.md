# HANDHELD Foundations

HANDHELD foundations are independently defined and are not inherited from STRATA.

- Color: HANDHELD semantic color tokens.
- Typography: HANDHELD type scale and text roles.
- Spacing: HANDHELD spacing scale.
- Motion: HANDHELD motion and reduced-motion rules.
- Iconography: Tabler Icons behind the HANDHELD `hh-icon` boundary.
